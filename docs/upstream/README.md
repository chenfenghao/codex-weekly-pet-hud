# Upstream reference

This fork preserves the history and MIT license of [himomohi/codex-pet-hud](https://github.com/himomohi/codex-pet-hud), based on commit `404fe55`.

The root README, Windows documentation and bilingual `site/` website describe this fork. Existing macOS code, unused original website artwork, older translations, and earlier changelog entries are retained as upstream reference and do not describe feature parity with the Windows weekly HUD.

The original Pages and cross-platform release workflows are archived under `workflows/*.yml.example`. Active workflows build/check the Windows weekly HUD and deploy this fork's website from `site/`. Releases are uploaded separately after desktop verification. The website retains explicit upstream attribution; its downloads and metadata refer to this fork. See [website maintenance](../WEBSITE.md).
