# Upstream reference

This fork preserves the history and MIT license of [himomohi/codex-pet-hud](https://github.com/himomohi/codex-pet-hud), based on commit `404fe55`.

The root README and Windows documentation describe this fork. Existing macOS code, the original website, older translations, and earlier changelog entries are retained as upstream reference and do not describe feature parity with the Windows weekly HUD.

The original Pages and cross-platform release workflows are archived under `workflows/*.yml.example` so they do not publish an unrelated website or old potion builds from this repository. The active workflow builds and checks the Windows weekly HUD. Releases are uploaded separately after desktop verification.
