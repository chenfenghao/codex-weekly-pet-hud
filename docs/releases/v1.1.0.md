## v1.1.0 · 中英文双语版 / Chinese & English

新增英文界面与英文说明文档，同一个便携包支持两种语言。

- 在「设置 → 语言 / Language」选择 **English** 或 **简体中文**，即时生效并自动保存。
- 覆盖状态条、详情、设置、提示、校验错误、托盘菜单和重置通知。
- 语言切换不改变额度、重置时间、刷新间隔、位置或通知去重记录；公告原文与粘贴输入保留原样。
- 包含完整英文 README、Windows 开发说明及示例配图。

Download the **Windows-x64.zip**, extract the entire archive, and run `CodexWeeklyPetHud.exe`. Open Codex Pet, click the HUD, then choose **设置 (Settings) → 语言 / Language → English**. The language changes immediately and is restored on restart. Both languages share the same executable.

The HUD, details, settings, tooltips, validation errors, tray menu and reset notifications are translated. Quota data, settings and notification history are preserved when switching languages. See the [English README](https://github.com/chenfenghao/codex-weekly-pet-hud/blob/main/README.en.md).

升级前请从托盘退出旧版。Exit the old version before upgrading. Settings are preserved. The portable package includes .NET 8, registers no automatic startup, and includes both READMEs. This is an unsigned Windows x64 build; verify it against `SHA256SUMS.txt`.

Language switching, saved preferences, bilingual parsing and English layout were checked on an interactive Windows desktop. Existing pacing, reset-policy and tray-overlap checks were also run.
