## Codex 周额度节奏挂件 v1.0.0

在真实 Codex Pet 上方查看剩余额度、使用节奏和社区重置信号。

### 下载与启动

下载下方 **Windows-x64.zip**，完整解压后运行 `CodexWeeklyPetHud.exe`，再在 Codex 中打开 Pet。保留程序旁的 DLL 文件。已包含 .NET 8 运行时，无需另装 .NET；便携版不注册开机启动。升级前请先通过系统托盘退出旧版。

### 本版功能

- 190 × 72 状态条：剩余、节奏、匀速应剩、每日建议和雷达状态。
- 自动读取周额度，默认 5 分钟，1–60 分钟可调；支持中文重置时间与剩余百分比粘贴导入。
- 重置雷达：新强信号或重置公告高亮并可触发 Windows 提醒；首次历史记录静默，同一状态不重复提醒。
- 托盘避让：系统面板展开时隐藏透明拖拽层，避免蓝牙等图标被拦截，面板关闭后恢复。

### 验证与范围

Windows x64；1120 个布局案例、174 个节奏/粘贴/界面检查、22 个雷达策略检查和15 个窗口命中/恢复检查通过，拖拽消息转发已验证。

这是未签名的便携构建，Windows 可能显示未知发布者提示。请核对同页 `SHA256SUMS.txt`。源码与文档见[仓库主页](https://github.com/chenfenghao/codex-weekly-pet-hud)。

社区公告不代表个人账户已到账；雷达不会兑换重置次数。自动用量读取依赖 Codex 本地登录和可能变化的客户端接口。公开雷达接口若拒绝原生网络客户端，可使用本机已安装 Python 作为兼容方式；程序不自动安装 Python。
